                  Netflix Movie Catalogue & Recommendation Analysis
              Exploratory Data Analysis | Python | Pandas | Data Analytics

**Project Overview**
Analysed 9,826 movie records to uncover patterns in genre distribution, audience ratings, popularity, release trends and original-language representation. The project uses exploratory data analysis to generate insights that can support content discovery and catalogue evaluation.

**Business Problem**
Understanding audience preferences and catalogue composition is essential for effective content discovery. This project investigates which genres dominate the catalogue, which categories receive stronger audience ratings, what drives popularity and how movie representation varies across decades and languages.

**Key Analysis & Findings**
•	Genre Distribution: Identified Drama as the most represented genre, followed by Comedy and Action.
•	Audience Ratings: History (6.97) and War (6.95) recorded the highest average ratings among genres with at least 30 movies.
•	Highly Rated Movies: Identified 367 movies with ratings of 8 or above and at least 100 audience votes.
•	Genre Popularity: Adventure (53.74), Fantasy (53.08) and Animation (52.43) achieved the highest average popularity scores.
•	Release Trends: 2021 recorded the highest annual movie representation with 713 titles.
•	Decade Analysis: The 2010s dominated the dataset with 3,968 movies.
•	Language Analysis: English represented 7,342 movies, while Japanese-language movies recorded an average rating of 6.98.

**Data Preparation & Methodology**
•	Analysed 9,826 usable movie records.
•	Expanded multi-valued genre records into 25,792 movie-genre records.
•	Prepared release-year data and created decade-level categories.
•	Applied aggregation, filtering and grouping techniques to evaluate catalogue and audience patterns.
•	Used rating and vote-count thresholds to identify highly rated titles.

**Tools & Technologies**
Python | Pandas | NumPy | Jupyter Notebook | Exploratory Data Analysis | Data Cleaning | Data Aggregation | Feature Engineering | Data Visualization

**Business Value**
The analysis highlights catalogue concentration, audience rating patterns and popular content categories. These insights can support content discovery, catalogue diversification and data-driven content evaluation.
